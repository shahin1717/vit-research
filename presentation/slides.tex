% SLIDE 3: 01. THE QUESTION (SHAHIN)
% -----------------------------------------------------------------------------
\begin{frame}{01. The Question}
\small
\textbf{Large ViTs quietly vandalise their own attention.}
\begin{itemize}\itemsep=1pt
\item Darcet et al.\ (ICLR 2024): in foundation vision transformers, a handful of background patch tokens acquire enormous activation norms. The \texttt{[CLS]} token routes much of its attention to them.
\item Those tokens sit in empty image regions and carry global context --- the model repurposes the image as scratch paper.
\item Their fix is architectural and almost free: give the model dedicated scratch tokens (\emph{registers}), and the artifacts disappear.
\end{itemize}

\smallskip
\begin{columns}[T]
\column{0.54\textwidth}
\begin{block}{The gap in that story}
Darcet demonstrated this where data is abundant. If registers absorb capacity the model would otherwise spend memorising, they should behave like a \textbf{structural regularizer} --- and a regularizer only proves itself where overfitting bites.
\end{block}

\column{0.44\textwidth}
\begin{alertblock}{Our core research question}
When a ViT is starved of data, do registers reduce the generalization gap --- and does that transfer to held-out test performance?
\end{alertblock}
\end{columns}
\end{frame}

% -----------------------------------------------------------------------------
% SLIDE 4: THREE HYPOTHESES (SHAHIN)
% -----------------------------------------------------------------------------
\begin{frame}{Three Hypotheses, Each Falsifiable}
\small
\begin{columns}[T]
\column{0.32\textwidth}
\begin{block}{\textbf{H1: Regularization}}
Registers shrink the generalization gap:
$$\Delta\mathcal{L} = \mathcal{L}_{\text{val}} - \mathcal{L}_{\text{train}}$$
and lower validation loss by acting as an architectural bottleneck.
\end{block}

\column{0.32\textwidth}
\begin{block}{\textbf{H2: Capacity Dilution}}
At $d = 192$ (ViT-Tiny), a large $K$ eats representational margin across softmax rows. Accuracy becomes non-monotonic in $K$.
\end{block}

\column{0.32\textwidth}
\begin{block}{\textbf{H3: Entropy Collapse}}
Registers prevent the layer-wise collapse of attention entropy $\bar{H}^{(l)}$ and suppress high-norm patch outliers.
\end{block}
\end{columns}

\medskip
\begin{center}
\footnotesize
\textbf{Why this is worth an experiment:} Nobody has tested registers as a regularizer, at compact scale, under strict data budgets. A clean answer is valuable whichever way it falls.
\end{center}
\end{frame}

\begin{frame}{02. Starving the Model}
\small
\begin{columns}[T]
\column{0.52\textwidth}
\textbf{Two controlled low-data regimes on CIFAR-100:}
\begin{itemize}\itemsep=3pt
\item \textbf{100 images/class (Primary):} 9{,}000 train / 1{,}000 val / 10{,}000 test. Strict data scarcity.
\item \textbf{300 images/class (Extension):} 27{,}000 train / 3{,}000 val / 10{,}000 test. Tests scale-invariance.
\item Upsampled to $224 \times 224$ so the pretrained patch grid ($14 \times 14 = 196$ patches) applies unchanged.
\item RandomResizedCrop, horizontal flip, AutoAugment; evaluation uses deterministic resize and centre crop.
\end{itemize}

\column{0.46\textwidth}
\begin{block}{The design that makes it a controlled test}
The subset is drawn under the run's own seed. So a seed is a replicate of the \textbf{whole pipeline}, not just weight initialization.
\end{block}
\smallskip
\begin{block}{Within-seed pairing}
Within each seed, all four register arms ($K \in \{0, 1, 4, 8\}$) see the \textbf{identical images} in the \textbf{identical batch order}.
\end{block}
\end{columns}
\end{frame}

% SLIDE 6: ONE THING MOVES, AND ONLY ONE (GULNISA)
% -----------------------------------------------------------------------------
\begin{frame}{One Thing Moves, and Only One}
\small
\begin{columns}[T]
\column{0.50\textwidth}
\textbf{Held fixed across every single arm:}
\begin{itemize}\itemsep=2pt
\item The exact same training images
\item The exact same train/validation split
\item The exact same batch order
\item The exact same 50-epoch schedule, AdamW ($5 \times 10^{-4}$), cosine decay, AMP, and batch size 64
\end{itemize}

\medskip
\textbf{Varied:} $K \in \{0, 1, 4, 8\}$, the number of register tokens. \textbf{Nothing else.}

\column{0.46\textwidth}
\begin{block}{Why pairing matters at $n = 3$}
Between-seed spread in validation accuracy is \textbf{2.17 pp} --- far larger than any effect registers could plausibly have.
\end{block}

\smallskip
Because the arms are strictly matched within each seed, we can \textbf{subtract that noise away} via paired differences ($\bar{\delta} = X_K - X_0$) instead of drowning in it.
\end{columns}
\end{frame}

% -----------------------------------------------------------------------------
% SLIDE 7: 03. WHAT A REGISTER IS (NARMINA)
% -----------------------------------------------------------------------------
\begin{frame}{03. Registers \& Instrumentation}
\small
\textbf{The token sequence, and the slice that decides everything:}
\begin{center}
\setlength{\fboxsep}{5pt}
\framebox[\linewidth]{
\texttt{[CLS]} $\parallel$ \textbf{$r_1$, $r_2$, $\dots$, $r_K$} ($K$ registers, no pos.\ embed) $\parallel$ \textbf{$p_1$, $p_2$, $\dots$, $p_{196}$} (196 spatial patches)
}
\end{center}

\smallskip
\begin{columns}[T]
\column{0.50\textwidth}
\textbf{Architectural Sequencing:}
\begin{itemize}\itemsep=2pt
\item Registers join every self-attention block and are discarded before the classification head.
\item Spatial patches start strictly at index $1 + K$.
\item Parameter cost at $K = 8$: 1{,}536 of 5.54\,M parameters --- a relative increase of just $2.8 \times 10^{-4}$.
\end{itemize}

\column{0.46\textwidth}
\begin{alertblock}{The off-by-$K$ trap}
Slice the spatial row from index 1 instead of $1 + K$ and register columns leak into the attention map. It still looks plausible --- which is exactly why our test suite rigorously asserts slice width across all depths.
\end{alertblock}
\end{columns}
\end{frame}

% -----------------------------------------------------------------------------
% SLIDE 8: TWO MECHANISM READOUTS (NARMINA)
% -----------------------------------------------------------------------------
\begin{frame}{Two Diagnostic Mechanism Readouts}
\footnotesize
\begin{columns}[T]
\column{0.48\textwidth}
\begin{block}{Layer-wise Attention Entropy}
$$\bar{H}^{(l)} = -\frac{1}{BHS} \sum_{b,h,i,j} A_{b,h,i,j}^{(l)} \log_2 A_{b,h,i,j}^{(l)}$$
\begin{itemize}\itemsep=1pt
\item Attention rows are probability distributions; entropy measures routing concentration.
\item Artifacts appear as entropy collapse in deep blocks.
\item Modern \texttt{timm} executes fused attention; our hook reconstructs the exact $[B, H, S, S]$ softmax matrix from unfused $Q, K$.
\end{itemize}
\end{block}

\column{0.48\textwidth}
\begin{block}{Patch-Norm Outlier Rate}
$$\rho^{(l)} = \frac{1}{BN} \sum_{b,n} \mathbf{1}\left[ \|x_{b, 1+K+n}^{(l)}\|_2 > \mu_b^{(l)} + 3\sigma_b^{(l)} \right]$$
\begin{itemize}\itemsep=1pt
\item The exact $3\sigma$ artifact definition: fraction of spatial patch tokens with anomalously large $L_2$ norm.
\item Evaluated on the residual stream, preventing LayerNorm squashing.
\end{itemize}
\end{block}
\end{columns}

\smallskip
\centering
\scriptsize Both metrics are read from the identical 64 test images across all runs for perfect input parity.
\end{frame}

\textbf{Is the null result an artifact of extreme starvation?}
\begin{itemize}\itemsep=1pt
\item Tripling data to 300 pc (27k train) surges baseline accuracy by \textbf{+6.14 pp} ($75.19\% \to 81.33\%$).
\item Yet registers still provide \textbf{zero benefit}:

  \end{itemize}
\item All pairwise differences are non-significant ($p > 0.50$).
\item \textbf{Conclusion:} The null result is \textbf{scale-invariant} across low-data budgets.
\end{itemize}

\textbf{Do registers even need to be trained?} Jiang et al.\ (NeurIPS 2025) redirect outlier neurons into an untrained slot at inference time. We ran an exploratory single-block test on our $K=0$ checkpoints:

\begin{tabular}{lccl}
\toprule

\textbf{Architectural note on Block 11:} Block 11 is followed by no further self-attention; the classification head reads solely \texttt{[CLS]}. \begin{frame}{Interpretation: A Scope Result, Not a Refutation}
\small
\begin{columns}[T]
\column{0.48\textwidth}
\textbf{Regime Mismatch:}
\begin{itemize}\itemsep=2pt
\item In Darcet et al., registers were present throughout pretraining at foundation scale.
\item Here, registers are added to an ImageNet-pretrained backbone and given 50 epochs over 9k--27k images.
\item The routing never reorganised --- entropy profiles remain the pretrained profile.
\end{itemize}

\column{0.48\textwidth}
\textbf{Artifacts Present but Unmoved:}
\begin{itemize}\itemsep=2pt
\item Control outlier rate ($1.23\%$) is $9\times$ the Gaussian $3\sigma$ rate: heavy-tailed structure is real.
\item But registers simply do not absorb it here.
\item \textbf{And $K=8$ is not free:} 8 content-free keys in a 205-token sequence at $d=192$ costs held-out accuracy and loss.
\end{itemize}
\end{columns}
\end{frame}

% SLIDE 16: CONCLUSION & TAKEAWAYS (SHAHIN)
% -----------------------------------------------------------------------------
\begin{frame}{Conclusion \& Defense Takeaways}
\small
\begin{enumerate}\itemsep=3pt
\item \textbf{No held-out benefit:} Across 24 controlled runs, no register configuration outperforms the register-free control on held-out test data.
\item \textbf{Validation illusion:} The apparent regularization signal on validation ($p = 0.024$) is an artifact of checkpoint selection on a noisy split; training loss was unmoved.
\item \textbf{Scale-invariance confirmed:} Tripling data to 300 pc (+6.14 pp gain) preserves the exact null result; test-time registers also produce no gain.
\item \textbf{Methodological lesson:} Never infer generalization from the split that performs model selection.
\end{enumerate}
